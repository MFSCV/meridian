# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and do not harass anyone. This applies in issues, pull requests, discussions and any other project space.

## Reporting

If someone's behaviour concerns you, use GitHub's **Report content** option on the comment, issue or pull request, or contact a maintainer privately through their GitHub profile. Reports are handled confidentially.

Maintainers may edit or remove contributions that break these rules and may block people who repeatedly do so.
